# SNAPTASK_CONSTITUTION_V2.md

## 0. STATUT DU DOCUMENT

Ce document constitue la SOURCE DE VÉRITÉ UNIQUE de SnapTask V2.

Il prime sur :
- tout code existant
- toute implémentation passée ou future
- toute interprétation produit
- toute logique SaaS classique

Toute divergence avec ce document est une ERREUR CRITIQUE.

---

## 1. IDENTITÉ PRODUIT

SnapTask est une plateforme transactionnelle d’actions IA.

SnapTask est :
- un distributeur automatique de résultats
- un registre d’obligations exécutables
- un intermédiaire contractuel de livraison

SnapTask n’est pas :
- un assistant
- un chat
- un SaaS par abonnement
- un outil de prompt
- un workflow engine
- une plateforme d’usage continu

---

## 2. ADN IMMUTABLE

Ces règles sont intangibles :
- SnapTask vend des résultats finis
- 1 tâche = 1 résultat = 1 paiement
- Aucun abonnement
- Aucun crédit
- Aucun engagement
- IA interne, jetable, non traçante
- Chaque tâche est :
  - stateless
  - déterministe
  - amnésique

RCG™ (Résultat Contractuel Garanti) :
- livré ou remboursé
- sans satisfaction subjective

---

## 3. DÉFINITION D’UNE TASK SNAPTASK

Une Task SnapTask est une unité contractuelle atomique qui :
- est définie avant achat
- a un prix connu
- a un résultat attendu explicite
- produit un livrable exploitable
- possède un critère de livraison vérifiable
- s’exécute une seule fois

Une Task n’est ni paramétrable librement,
ni conversationnelle,
ni évolutive après paiement.

---

## 4. MODÈLE TRANSACTIONNEL

- Paiement unitaire
- Paiement avant exécution

Une transaction déclenche :
1. exécution
2. validation
3. livraison

Si la livraison conforme échoue → remboursement automatique (RCG™).

---

## 5. LE CATALOGUE

Le catalogue est le produit.

- Il définit l’intégralité des capacités de SnapTask
- Toute action hors catalogue n’existe pas
- Le catalogue est :
  - fini
  - versionné
  - auditable

Une task peut être :
- ajoutée
- dupliquée
- retirée

Une task ne peut pas être modifiée silencieusement.

---

## 6. SNAPTASK & AIRBNB — PÉRIMÈTRE EXACT

### 6.1 Principe fondamental

SnapTask n’est pas un système Airbnb complet.
SnapTask propose une version Airbnb Lite, documentaire, transactionnelle.

Toute logique Airbnb avancée appartient à SnapTaskStay.

---

### 6.2 Airbnb Lite — Autorisé dans SnapTask

SnapTask peut proposer uniquement des tasks documentaires et de preuve,
sans structure métier persistante.

Documents autorisés :
- Lettre de bienvenue voyageur
- Fiche d’arrivée
- Fiche de départ
- Règlement simple

---

### 6.3 États des lieux par photos horodatées (AUTORISÉ)

Tasks autorisées :
- État du logement — AVANT séjour
- État du logement — APRÈS séjour

Conditions strictes :
- dossier de preuves
- photos horodatées
- document final figé
- aucune persistance métier

---

### 6.4 Interdictions Airbnb

SnapTask ne gère pas :
- logements
- séjours
- conciergerie
- workflows Airbnb
- preuves cumulatives
- litiges

Tout cela appartient exclusivement à SnapTaskStay.

---

## 7. FRONTIÈRE SNAPTASKSTAY

SnapTaskStay est une application métier autonome dédiée à Airbnb.

Aucune dépendance logique ou technique ne doit exister entre SnapTask et SnapTaskStay.

---

## 8. DUPLICATION DES TASKS

Une task peut être dupliquée par :
- langue
- pays
- cadre réglementaire
- format de livrable

Sans changement UX ni exposition IA.

---

## 9. SUPPRESSION DES TASKS

Une task est supprimée sans débat si :
- non rentable
- trop instable
- valeur non mesurable
- subjectivité introduite

---

## 10. INTERDICTIONS GLOBALES

- Pas de chat
- Pas d’assistant
- Pas de prompt visible
- Pas d’abonnement
- Pas de crédits
- Pas de workflow
- Pas de feature creep
- Pas de logique métier persistante

---

## 11. PRINCIPE FINAL

SnapTask V2 est un système d’exécution contractuelle.

Il préfère retirer, simplifier, facturer plus cher et livrer mieux,
plutôt qu’ajouter, expliquer ou promettre.

FIN DE LA CONSTITUTION SNAPTASK V2
